## 5. 緊急対応推奨（Phase 1 着手前に実施）

優先度高い順:

1. **`/rallies/{id}` → `/routes/{id}` URL移行 + 301リダイレクト**
   - SNSシェア・QR印刷物への影響回避
   - DBスキーマ `rallies` → `routes` も同時マイグレーション

2. **タイトル・metaの「スタンプラリー」全削除**
   - 検索インデックス影響大
   - OGPの旧文言が拡散されるのを止める

3. **「注目のナラティブ」→「注目のルート」**
   - 用語v1.1で「ナラティブ」はユーザー向け禁止語
   - トップページの目立つ場所

4. **ダミーデータ・サンプル埼玉ルート削除**
   - パイロットエリア（中目黒）のシードデータに差替
   - 「ダミー住所 1」表示は信頼性を下げる

5. **フッターリンク切れ修正**
   - お問合せ・運営会社・利用規約・プラポリ
   - 規約類は Phase 1 開始前の弁護士確認後に差替

## 8. リスク

| リスク | 影響 | 対策 |
|---|---|---|
| 旧URLが既にSNSシェア・QR印刷されている | 旧ユーザー到達不可 | 301リダイレクト最低6ヶ月維持 |
| サンプルデータ削除でユーザー動線が消失 | β募集前なら影響小 | パイロット中目黒データ投入と同時実施 |
| 内部DB構造が深く `rallies` 依存 | マイグレーション大 | リポジトリ取得後にコスト試算 |
| 規約・プラポリ未整備でβ開始不可 | リリース遅延 | 弁護士確認を Phase 1 開始前に完了 |
