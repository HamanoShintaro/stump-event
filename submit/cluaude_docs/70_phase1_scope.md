## 1. Phase 1 の目的

**2026年7〜9月**：1エリア・50人規模で **MVPの「面白さの最低ライン」が成立するか** を検証する。

| 指標 | 基準 |
|---|---|
| 参加者数 | n=50人以上 |
| リピート率（2回目参加） | 30%以上 |
| 「また使う」回答率 | 60%以上 |
| B②→A①起動率 | 40%以上 |
| ルート完走率 | 50%以上 |

これを **全て満たせば Go**、いずれか欠ければ **No-go（Phase 2準備停止 → 原因分析）**。

## 6. KPI測定の実装

| 指標 | 計測方法 |
|---|---|
| 参加者数 | `users` テーブル新規登録数 |
| リピート率 | 2回以上の `stamp_events` を持つユーザー / 全ユーザー |
| 「また使う」回答率 | 完走後アンケート（Google Form 等、外部）|
| B②→A①起動率 | `trigger_qrs` 経由のユーザー / ルート開始者 |
| ルート完走率 | `user_route_progress.status = 'completed'` / `started_at IS NOT NULL` |

KPIダッシュボードは Retool で簡易構築（運営確認用）。

## 7. リスクと対策

| リスク | 対策 |
|---|---|
| GPS精度が屋内で不安定 | QRフォールバック必須 |
| パイロット参加者が集まらない | Owner個人ネットワーク + 中目黒商店街経由で募集 |
| 史実確認が間に合わない | スポット数を3に絞り、確実な史実のみ採用 |
| 押印セレモニーが軽く感じる | 内部テスト時にユーザビリティテスト3名で確認 |
| 称号デザインが「モダン和風」になっていない | デザイナー外部委託検討（[90](./90_open_questions.md) #3） |

- SNSシェア機能をスポット単体にも拡張

## 9. No-go時の対応

いずれかの基準を欠いた場合:

1. **原因分析** を2週間以内に完了（参加者インタビュー・ログ分析）
2. **再設計** が必要な領域を特定（コアループ / ナラティブ / セレモニー / 動機）
3. **Phase 1.5** として小規模再検証（追加50人 / 1ヶ月）を Owner と相談
4. それでも基準を満たさない場合は **事業モデル再検討**

「失敗を直視して撤退判断もできる」ことが Phase 1 の隠れた目的。
