# 52. ポストルートカード（ルート完走）仕様

> 最終更新: 2026-05-31 / 出典: SHUIN_統合仕様書.md §4-4
> 関連: [51_post_scan_card.md](./51_post_scan_card.md) / [53_stamp_ceremony.md](./53_stamp_ceremony.md)

---

## 1. 役割

ルート全スポット完走後、完走セレモニー（C1〜C4・約5秒）終了後に表示される画面。

**MVP最重要のSNSシェアタイミング**。称号カードを静止画として切り出してシェアする。

---

│                                 │
│  [ルート名]の踏破者              │ ← 完走称号名（金・モダン和風）
│  Trailblazer of [Route Name]    │ ← 英字サブタイトル
│                          ★★★  │
│                                 │

│  2026.05.15                     │ ← 完走日
│                                 │
├─────────────────────────────────┤
│  ▪ 中目黒橋 ─ 2026.05.15       │
│  ▪ 石碑の路地 ─ 2026.05.15     │ ← スポット一覧（来訪日付）

---

## 3. 表示データソース

API `GET /routes/{route_id}/completion-status` のレスポンスから:

| 表示要素 | データ |
|---|---|
| ルート名 | `route_name` |
| 完走称号名 | `completion_title.name` |
| 英字サブタイトル | `completion_title.subtitle_en` |
| レア度 ★ | `completion_title.rarity` |
| スポット一覧 | `spots_summary[]` |
| 最終F7全文 | `final_f7_full` |
| 初完走フラグ | `is_first_completion` |
| シェア画像URL | `share_image_url` |

---

## 4. 動作ルール

| 操作 | 挙動 |
|---|---|
| 自動表示 | 完走セレモニー C4 終了後にスライドイン |
| タイムアウト | **なし** |
| [シェアする] | ネイティブシェアシート起動 |
| [保存する] | 訪問ログに保存し、マップへ戻る |
| [次のルートを探す] | マップに戻り、未完走ルートにハイライト |
| 戻るボタン（OS） | [保存する] と同等 |

---

## 5. SNSシェアの仕様（MVP）

### 5-1. シェア形式

| 形式 | 用途 | サイズ |
|---|---|---|
| **静止画** | Twitter/X, Instagram, LINE | 16:9 と 1:1 の2サイズ自動生成 |
| **テキスト** | リンク + 文言 | URL + 一文 |

### 5-2. シェア文言テンプレート

```
[ルート名] を完走しました ✨
称号:「[称号名]」を授かりました
SHUIN まちのしるし
https://shuin.app/r/{route_id}
```

### 5-3. 画像生成

- **画像生成方式（推奨）**: サーバーサイドで PNG 生成（Vercel OG Image / `@vercel/og` 利用可）
- 静止画には以下を含む:
  - 称号名（日本語・英字）
  - レア度 ★表示
  - ユーザー名（任意）
  - 完走日
  - ロゴ
- ユーザーごとにキャッシュ（再シェア時の高速化）

### 5-4. プライバシー

- ユーザー名はopt-in表示（デフォルトはイニシャル）
- スポット名は含めるが、住所・座標は含めない

---

## 6. 動画シェア（MVP非対応）

完走セレモニーの動画切り出し（5秒）は **Phase 2以降**。MVPは静止画のみ。

理由: 動画は実装工数が大きく（クライアントレンダリング or サーバーサイドFFmpeg）、シェア訴求は静止画で十分達成可能。

---

## 7. スポット完走 vs ルート完走 — 設計比較

| 項目 | ポストスキャンカード（スポット） | ポストルートカード（ルート完走） |
|---|---|---|
| 称号レア度 | ★1〜2（カテゴリA/C） | ★2〜3（カテゴリB） |
| 演出 | 自動7秒セレモニー後 | 自動5秒完走セレモニー後 |
| ナラティブ | F7全文（120字）＋次スポット引力 | F7全文（最終・完結）＋ルート来歴 |
| CTA | 次のスポットへ | 次のルートを探す |
| SNSシェア | Phase 2 | **MVP** |

---

## 8. 完走時の称号付与（複数）

ルート完走時、以下が同時付与される場合がある。

| カテゴリ | 称号例 | レア度 |
|---|---|---|
| B | [ルート名]の踏破者 | ★2 |
| B | [ルート名]の語り手（F7全テキスト受取済） | ★3 |
| C | 語り継ぐ者（1ルート全F7受取） | ★3 |
| G | [エリア名]マスター（エリア内全ルート完走時） | ★3 |
| D | 創設者 / ベータ探索者（Phase 1参加者） | ★3/4 |

完走カードには **最上位レア度の称号を主に表示**、他は副次として小さく表示。

---

## 9. デザイン指針

- ポストスキャンカード（[51](./51_post_scan_card.md)）と統一トーン
- 「COMPLETE」のゴールドラベルで完走感を明確化
- スポット来歴は時系列の足跡を強調

- [ ] シェア画像の事前生成 or オンザフライ生成
- [ ] スポット来歴の時系列ソート

- [ ] 「次のルートを探す」マップ遷移＋未完走ハイライト
- [ ] 訪問ログから再読可能（削除不可）
