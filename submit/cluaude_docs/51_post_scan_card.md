# 51. ポストスキャンカード仕様

> 最終更新: 2026-05-31 / 出典: SHUIN_統合仕様書.md §4-3
> 関連: [53_stamp_ceremony.md](./53_stamp_ceremony.md) / [61_narrative_logic.md](./61_narrative_logic.md)

---

## 1. 役割

押印セレモニー（F9）終了後、ユーザーが自分のペースで物語の完結を受け取り、次スポットへ向かう動機を獲得する画面。

**重要設計**: マップに直接戻らない。必ずこのカードを経由する。

---

## 2. 画面仕様

```
┌─────────────────────────────────┐
│  ★★★                          │ ← 称号レア度
│                                 │
│  [スポット名]の記憶              │ ← 称号名（金テキスト・モダン和風）
│  Memory of [Spot Name]          │ ← 英字サブタイトル
│                                 │
│  2026.05.15  #47番目の来訪者    │ ← 来訪日・来訪者番号
├─────────────────────────────────┤
│                                 │
│  この場所で働いていた染物職人の  │
│  多くは、1964年の東京五輪を前に  │ ← F7全文（ユーザーペースで読む）
│  川を離れた。整備が進んだ川は、  │
│  職人たちの仕事場ではなくなった。│
│  橋の下の石積みは、当時のものが  │
│  今も使われている。             │
│                                 │
│  次の場所に、彼らが最後に集まった│ ← 次スポット引力（F7最終文）
│  路地の記録がある。             │
│                                 │
├─────────────────────────────────┤
│  [ 次のスポットへ → 石碑の路地 ]│ ← CTA（スポット名入り）
│  [ 後で読む  ]                  │ ← 保存してマップへ戻る
└─────────────────────────────────┘
```

---

## 3. 表示データソース

API `POST /checkin` のレスポンスから:

| 表示要素 | データ |
|---|---|
| 称号レア度 ★ | `title.rarity` |
| 称号名（日本語） | `title.name` |
| 英字サブタイトル | `title.subtitle_en` |
| 来訪日 | `title.visited_at` |
| 来訪者番号 | `visitor_number` |
| F7全文 | `narrative.f7_full` |
| 次CTA文言・遷移先 | `next_spot.name` / `next_spot.id` |
| CTA変化（最終） | `next_spot.is_final` |

---

## 4. 動作ルール

| 操作 | 挙動 |
|---|---|
| 自動表示 | F9から自動でスライドイン |
| タイムアウト | **なし**。ユーザーが読み終わるまで滞在 |
| [次のスポットへ] | マップに遷移、次スポットがハイライト状態 |
| [後で読む] | F7全文を訪問ログに保存し、マップへ戻る |
| 戻るボタン（OS） | [後で読む] と同等 |
| 最終スポットの場合 | CTAが「ルート完走 — 称号を受け取る」に変わる |

---

## 5. 最終スポット時の挙動

`next_spot.is_final = true` の場合:

```
┌─────────────────────────────────┐
│ ...称号・F7全文（完結版）...     │
│                                 │
│ ※次スポット引力の文は入れない   │ ← narrative_spec準拠
│ ※F7全文は「完結の余韻」で終わる │
├─────────────────────────────────┤
│  [ ルート完走 — 称号を受け取る ]│
└─────────────────────────────────┘
```

CTAタップで完走セレモニー C1〜C4 に遷移（[53参照](./53_stamp_ceremony.md)）。

---

## 6. 再読可能性

F7全文は **訪問ログから常時参照可能**（削除不可）。

```
SHUIN帳（/lifelog）
  → スポットタップ
    → /lifelog/spots/{spot_id}
      → F7全文を再表示（同一レイアウト）
```

---

## 7. SNSシェア（MVP非対応）

スポット単体のシェアは MVP では実装しない。ルート完走時のみシェア機能を提供（[52参照](./52_post_route_card.md)）。

理由: 完走の方が達成感が高く、見た人の「行ってみたい」訴求力が強い。

---

## 8. デザイン指針

| 要素 | 仕様 |
|---|---|
| 背景 | 深黒（#0D0D0D） |
| 称号テキスト | 金（#C9A84C） |
| 英字サブタイトル | 細セリフ体（#888888） |
| 本文（F7全文） | 白（#F2F2F2）・16px・行間1.8 |
| CTA（次スポット） | 金背景・黒テキスト・大型タップ領域 |
| CTA（後で読む） | 透明背景・金線枠・金テキスト |
| 装飾 | 細い縦罫線・四隅のわずかな金縁のみ |

グラデーション・派手なエフェクトは禁止。

---

## 9. アクセシビリティ

- F7全文のフォントサイズ調整: 設定画面から大/中/小
- 称号名・本文には `aria-label` を付与（VoiceOver対応）
- カラーコントラスト: WCAG AA 準拠
