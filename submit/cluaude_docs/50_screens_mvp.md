## 2. ホーム画面（/）

### レイアウト

```
┌─────────────────────────────────┐
│ [SHUIN ロゴ]    [プロフィール] │
├─────────────────────────────────┤
│ 🔥 EVENT  残り3日               │ ← ③イベントルート時のみ表示
│ 「○○MALL 10周年ルート」         │
├─────────────────────────────────┤
│ 注目のルート                    │ ← 用語: 「ナラティブ」ではなく「ルート」
│                                 │
│ ┌─────────────────────────────┐ │
│ │ [画像] 目黒川、昭和の痕跡   │ │ ← ①プラットフォーム（金ピン）
│ │ 発見したい・45分・★★★     │ │
│ └─────────────────────────────┘ │
│                                 │
│ ┌─────────────────────────────┐ │
│ │ [画像] ○○MALL presents     │ │ ← ②施設（施設カラー）
│ │ 達成したい・60分・デート向け │ │
│ └─────────────────────────────┘ │
├─────────────────────────────────┤
│ [🗺 地図から探す] [🔍 検索]    │
└─────────────────────────────────┘
```

### 表示ロジック

- ログイン済: 現在地から近いルートを優先表示（GET /routes/nearby）
- 未ログイン: 全国注目ルート（Phase 1ではパイロット中目黒）
- ③イベントルート期間中はトップに帯バナー
- ④スポンサードルートはバッジ表示（Phase 2〜）

## 3. マップ画面（/map）

### レイアウト

```
┌─────────────────────────────────┐
│ ← [SHUIN ロゴ]                  │
├─────────────────────────────────┤
│ 🗺️ 地図から探す                  │
│ 現在地周辺のルートピンを表示     │
├─────────────────────────────────┤
│                                 │
│  [Google Maps]                  │
│  - 金ピン: ①プラットフォーム    │
│  - 施設カラー: ②施設常設        │
│  - 点滅: ③イベント              │
│  - ブランドカラー: ④スポンサード │
│                                 │
│  [ピンタップ] → カード吹き出し  │
│                                 │
├─────────────────────────────────┤
│ [リスト表示への切替]            │
└─────────────────────────────────┘
```

### マップピン表示ルール

| ルート種別 | ピン色・形状 | 追加表示 |
|---|---|---|
| ①プラットフォームルート | 金ピン・標準 | なし |
| ②施設常設ルート | 施設カラーピン＋施設ロゴアイコン（小） | 「○○施設 協力」クレジット |
| ③イベントルート | 点滅アイコン | 残り日数バッジ（「残3日」） |
| ④スポンサードルート | ブランドカラーピン＋ブランドロゴ（小） | 「BRAND presents」 |
| B②トリガー（QR設置場所） | **マップ非表示（原則）** | 偶然発見の演出維持 |

### 技術

- Google Maps Platform（Maps JavaScript API）
- ピンクラスタリング: スポット密集時の集約表示
- 現在地ボタン
- 半径2km範囲のルートを `/routes/nearby` から取得

### 機能

- ルートタブ → 進行中・完走済ルート

## 7. 称号一覧（/badges）

### フィルタ

- レア度（★1〜★5）
- カテゴリ（A:来訪 / B:ルート完走 / C:物語 / D:創設者 / E:季節 / F:累計 / G:地域 / H:希少 / I:イベント）
- 取得日

### 表示

- 取得済: フルカラー・モダン和風カード
- 未取得: シルエット表示（条件文のみ。獲得後にイメージ解放）

## 8. プロフィール・設定（/settings）

### 項目

- アカウント情報（表示名・メール）
- 通知設定（プッシュ通知 ON/OFF）
- データ管理（退会・データダウンロード）
- 利用規約・プライバシーポリシーリンク
- ログアウト

## 9. レスポンシブ・PWA対応

- **PWA前提**: モバイルブラウザでホーム画面追加すればネイティブ風に
- ブレークポイント: 〜768px（スマホ）/ 769〜1024px（タブレット）/ 1025px〜（PC・閲覧用）
- スマホ縦持ち最適化を最優先
- PC版は閲覧用（マップ・ルート詳細・SHUIN帳）。押印はモバイル限定（GPS精度・QRカメラ依存）

---

## 10. デザイントーン

- **モダン和風**（称号カードと同系統）
- 主色: 深黒（#0D0D0D）背景 / 金（#C9A84C）アクセント
- 装飾は最小限。グラデーション禁止
- 文字: 横書きベース。称号のみ縦書き選択可（Phase 2）

参考: NieR:Automata / Ghost of Tsushima のUIトーン。**派手さではなく重み。**
