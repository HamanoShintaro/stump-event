# 自由が丘 週末ペーパーテストキット
> アプリなしで、SHUINの"芯"を手作業で再現して歩くための道具一式。
> 目的：実装前に「この体験は面白いか」という最大リスク仮説を検証する。
> 原則：**実装は簡略化してよい。体験の芯（自答・気づき・押印の儀式）は簡略化しない。**

---

## 用意するもの（印刷 or 手書き）

- **SHUIN帳**（下記）…A5一枚。押印スロット5つ＋称号欄
- **問いカード**…1枚（冒頭に読む）
- **手がかりカード ×5**…各スポットで開く（先に読まない・封をする）
- **称号カード ×4**…自答の結果渡される
- スタンプ or シール（押印の儀式用）／封用シール（手がかりカードを隠す）

---

## 0. 冒頭（駅で読む）— 問いカード

```
┌─────────────────────────────┐
│  自由が丘の "自由" は、       │
│  何から生まれたのか？         │
│                             │
│  5つの場所に、答えではなく     │
│  食い違う"手がかり"がある。    │
│  歩き終えたら、あなたの答えを   │
│  選ぶ。答えで称号が変わる。     │
└─────────────────────────────┘
```

## 2. 押印の儀式（各スポットで・手作業）

ボタンを押す代わりに、**所作**にする。これが「証を授かる」感の検証。

1. スポット圏内に着いたら、まず**手がかりカードはまだ開けない**（封のまま）
2. その場の**物理サプライズを自力で探す**（下記。見つける＝発見の快感）
3. 見つけたら、SHUIN帳のスロットに**スタンプを押す/シールを貼る**（2〜3秒、丁寧に）
4. **押した直後に**、封を剥がして手がかりカードを開く（押印→ご褒美の順）
5. 最後に「次への引き」を声に出して読み、次へ

> 検証：この所作が「ただのチェック」でなく「儀式」に感じられるか。感じないなら演出が足りない。

## 3. スポット別：物理サプライズ（自力で探す）＋手がかりカード

### ①熊野神社
- 探す：授与所の**本物の御朱印**。「これがSHUINの原本」
- 手がかり（押印後に開く）：「ここは"自由が丘"の前、"谷畑(やばた)"という谷あいの土地だった。神様は今も谷畑の権現さま。"自由"は最初の名前じゃない。」
- 次への引き：「次は水もないのに運河がある。なぜ人はないものを描く？」

### ②La Vita
- 探す：運河の水の行き先（流れているか／循環か）
- 手がかり：「水のない街が運河を描き、"ヴェネツィア"という他人の名を名乗る。なぜ自分でない名前で自分を語る？」
- 次への引き：「次は"自由"を売る店。でも街の名のもとの自由とは別物の自由を。」
- ※検証メモ：気づきが弱ければ「写真主役・気づき軽め」に切り替え判断

### ③TODAY'S SPECIAL
- 探す：面する道の名「**学園通り**」の標識（消えた学校名の名残）
- 手がかり：「街の名は昭和2年"自由ヶ丘学園"＝教育の自由。今この店が売るのは"暮らしの自由"。同じ言葉で中身が入れ替わった。」
- 次への引き：「次は時間が止まったビル。隣に新しい塔が建つのに、なぜ残る？」

### ④自由が丘デパート
- 探す：迷路の奥の**昭和のまま更新されていない一軒・手書き看板**
- 手がかり：「再開発の塔の隣で、このビルだけ昭和の密度のまま。自由とは新しくなり続けることか、残すと決めることか。」
- 次への引き：「最後に気づく。さっきからずっと、隠されたものの上を歩いていた。」

### ⑤九品仏川緑道 ★山
- 探す（データ確認済み・実物）：橋名遺構「**鶯谷橋**」「**城向橋**」／川の**蛇行カーブ**
- 手がかり：「あなたはさっきから川の上を歩いている。九品仏川は地下に隠された。見えない川の上に、おしゃれな街が立っている。さあ、あなたの番だ。」
- ※ここで「川の上を歩いていた」と**ハッとするか**が最重要検証

## 4. 自答（最終・緑道で）— 4択カード

> 問い再掲：自由が丘の"自由"は、何から生まれたか？ あなたの答えを選ぶ。

```
A「名乗ること」   谷畑が学校の名を借り自由が丘と名乗った
   → 称号：蒼穹（あおぞら）
B「手放すこと」   本物の川を地下に隠し湿地を捨てて理想を描いた
   → 称号：暗渠を見た者
C「選び直し続けること」 教育→暮らし→再開発と意味を更新し続ける
   → 称号：更新する街の住人
D「借り物かもしれない」 運河も学校名も外から借りた
   → 称号：引用者
```

選んだら、対応する称号カードをSHUIN帳に記入。

## 5. 検証ログ（歩き終えて）

| 確認 | 結果 |
|---|---|
| 押印を"儀式"と感じたか | はい / いいえ |
| 物理サプライズを自力で見つけられたスポット数 | ／5 |
| 緑道で「川の上を歩いていた」とハッとしたか | はい / いいえ |
| 自答を**選びたくなったか** | はい / いいえ |
| 別の答えでもう一周したくなったか | はい / いいえ |
| スタンプラリーと違うと感じたか | はい / いいえ |
| 一番の弱点 | |
| 総合：実装に進んでよいか | Go / 一部再設計 / No |

> この6つの「はい」がどれだけ取れるかが、SHUINの価値仮説の答え。
> ここが弱いなら、削るべきは体験でなく演出の作り込み方を見直す。
