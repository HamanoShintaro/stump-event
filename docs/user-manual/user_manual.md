# SHUIN（まちのしるし）公式ユーザーマニュアル

> **街を歩いて、しるしを刻む。**  
> **訪れた場所が、あなたのしるしになる。**

本マニュアルでは、「SHUIN まちのしるし」の基本的な使い方から、物語の楽しみ方、友人と一緒に街を巡る「連れ立ち」機能、そして歩みの証である「SHUIN帳」や「称号」の仕組みまでを詳しくご案内します。

---

## 序章：SHUIN（まちのしるし）とは

**SHUIN（まちのしるし）** は、街に点在する魅力的な場所（スポット）をテーマや物語に沿ってめぐり、訪れた証として **「SHUIN（しるし）」** を刻んでいく街歩きライフログサービスです。

### 基本用語ガイド

| 用語 | 意味・説明 |
| :--- | :--- |
| **ルート** | 特定のテーマや地域に沿って厳選された、複数のスポットをめぐる散策コースです。 |
| **物語** | ルートや各スポットに秘められた背景・歴史・エピソードです。スポットに近づき、押印することで少しずつ紐解かれていきます。 |
| **スポット** | ルートを構成する個々の目的地（神社仏閣、名店、建築、風景、路地など）です。 |
| **押印（おういん）** | 実際にスポットを訪れ、GPS（位置情報）または現地QRコードによって来訪のしるしを刻む行為です。 |
| **SHUIN（しるし）** | 押印によって授かるデジタルの朱印（収集物）です。ルートのカテゴリに応じた美しい印影が刻まれます。 |
| **SHUIN帳** | あなたがこれまでに刻んだ「スポットの来訪印」や、ルートを最後まで巡って授かった「ルートの踏破印」、現地で残した写真・感想メモを振り返る自分だけの記録帳です。 |
| **踏破印（メイン・サブ）** | ルート内のすべてのスポットをめぐり終えた際（完走時）に授かる特別なSHUINです。「自答の儀」があるルートでは、あなたが選んだ答えに応じた副印（サブ）が共に刻まれます。 |
| **称号** | 地域・路線・都道府県・印目（カテゴリ）・累計押印数・季節など、あなたの歩みの積み重ねに応じて授かる栄誉です。 |
| **連れ立ち** | 6桁の招待コードを使って友人や家族と同じルートを一緒にめぐり、到着の通知や思い出の写真・メモを共有できるグループ機能です。 |

## 第1章：ルートを探す・出会う（ルート探索・発見ドメイン）

その日の気分や訪れる街、空き時間、予算に合わせて、あなたにぴったりのルートを見つけることができます。

### 1.1 トップページ「少し外へ出て、街を再発見する」と街歩きメトリクス
- トップページ（`/`）には、日常の延長でふらっと街へ出かけられるよう **「少し外へ出て、街を再発見する」** コンパスと3つの切り替えタブが用意されています：
  1. **✨ 注目のルート**: おすすめの物語ルートを一覧表示します。
  2. **📍 現在地から近い順**: 位置情報（GPS）をもとに、今いる場所から最も近いルート順に表示します。
  3. **☕ 30〜45分の気軽な街歩き**: ちょっとした空き時間や散歩にぴったりの短時間ルートに絞り込みます。
- 各ルートのカードには、街歩きの計画が立てやすい **街歩きメトリクス（Walk Metrics）** が表示されます：
  - **現在地からの距離・徒歩分数バッジ**: 現在地からそのルートの最初のスポットまでの直線距離（`〇〇 m` / `〇〇 km`）と徒歩の目安分数（`徒歩約 〇〇 分`）
  - **スポット数・総歩行距離・所要時間**: 例 `全5箇所 ・ 約1.8km ・ 約40分`
  - **カテゴリ・都道府県・エリアタグ**（画面左上）
  - **予算の目安**（`~1,000円` / `~5,000円` / `5,000円~`）
  - **参加人数（足跡マーク）**・**保存数（星マーク）**

### 1.2 キーワード（駅名・街名・スポット名）・所要時間・条件で絞り込む
- トップページ中央の **「検索して探す」** ボタン、または画面右上の **虫眼鏡アイコン（🔍）** をタップすると、検索モーダルが開きます。また、ルート一覧画面（`/routes`）上部でも直接フィルターや並び替えを行えます。
- 以下の条件を組み合わせてルートを自在に絞り込めます：
  1. **キーワード検索**: 駅名（例：`自由が丘`、`岩槻`）、街・エリア名、スポット名、テーマワードなど自由な言葉で検索できます。
  2. **所要時間フィルター**: `すべて` / `〜30分（気軽な散歩）` / `〜45分` / `〜60分` / `60分以上（じっくり散策）`
  3. **並び替え（ソート）**: `おすすめ順` / `現在地から近い順` / `所要時間が短い順`
  4. **都道府県**: 東京都、神奈川県、埼玉県、千葉県、大阪府、京都府、福岡県、北海道、沖縄県 など
  5. **カテゴリ（全10種）**:
     - `食べたい`（飲食店、カフェ、食べ歩き）
     - `見たい`（絶景、建築、展示、夜景）
     - `体験したい`（アクティビティ、ワークショップ）
     - `集めたい`（御朱印、しるし、聖地）
     - `推しに触れたい`（アニメ、ドラマ、アイドル）
     - `学びたい`（博物館、工場見学）
     - `癒されたい`（温泉、自然、動物）
     - `達成したい`（登山、踏破）
     - `人と過ごしたい`（デート、家族、交流）
     - `地域を感じたい`（ご当地、歴史、文化）
  6. **予算**: `〜1,000円` / `〜5,000円` / `5,000円〜`

### 1.3 気になるルートを保存する（「栞」ブックマーク機能）
- ルート詳細画面（`/routes/[id]`）にある **「🔖 このルートを保存する（栞）」** ボタンをタップすると、いつでも見返せるよう「栞」を挟んで保存（ブックマーク）できます（保存中は **「🔖 保存済み（栞を外す）」** と表示されます）。
- 保存したルートは、マイページ（`/mypage`）の下部にある「🔖 保存したルート」または一覧画面（`/mypage/bookmarks`）からいつでも確認・解除できます。

### 1.4 地図から現在地周辺のルートを探す
- トップページの **「地図から探す」** ボタン（`/map`）をタップすると、現在地周辺のマップが表示されます。
- マップ上には、各ルートの中心位置に **カテゴリごとの絵文字ピン**（🍔・👀・🏮など）が表示されます。
- ピンをタップすると、そのルートに含まれるスポットが順番に赤い破線で結ばれるアニメーションが再生され、画面下部にルートの概要カードが現れます。
- **「このルートを巡る」** をタップすると、ルート詳細画面へ進みます。
- マップ右下の **「◎」ボタン** を押すと、いつでも自分の現在地へ表示を戻すことができます。

### 1.5 街角のQRコードから物語を始める
- 街中に設置された特別な案内QRコード（`/triggers/[token]`）をスマートフォンのカメラで読み取ると、その土地に秘められた物語のプロローグ（Act 0）が紙芝居のように再生されます。
- プロローグを読み終えたあと **「この物語を巡る ➔」** をタップすると、そのままルートへの参加が完了し、最初のスポットが目的地に設定された状態でマップ画面が開きます。

## 第2章：ルートに参加し、街をめぐる（ルート参加・ナビゲーションドメイン）

気になるルートを見つけたら、参加して街歩きを始めましょう。

### 2.1 ルートに参加する（プロローグ演出と進行中ルートのルール）
1. ルート詳細画面（`/routes/[id]`）を開き、内容やスポット一覧、授かる踏破印の予告を確認します。
2. **「このルートに参加する」** ボタンをタップします（未ログインの場合はGoogleログイン画面へ進みます）。
3. 参加が完了すると、ルートの世界観へ誘う **プロローグアニメーション** が再生されます（画面をタップすると次の段落へ進めることもできます）。
4. アニメーション終了後、自動的に「次の行き先を選択」画面へ移動します。

> **💡 進行中ルートの大切なルール（同時進行1本・24時間有効）**
> - **進行中に設定できるルートは最大1本まで** です。すでに別のルートが進行中のときに新しいルートへ参加しようとすると、切り替えの確認画面が表示されます。
> - **参加から24時間** が経過すると、そのルートは自動的に「進行中」から外れます。
> - **過去の記録は消えません**: 別のルートに切り替えたり、24時間が経過して進行中から外れたりしても、**それまでに獲得した押印（SHUIN）や参加履歴はすべてSHUIN帳に残ります**。いつでも「このルートに再参加する」ボタンから続きをめぐることができます。

### 2.2 次の目的地（スポット）を設定する
- ルート参加直後の **「次の行き先を選択」画面（`/routes/[id]/destinations`）**、または **ルート詳細画面のスポット一覧** から、最初に向かうスポットの **「ここを行き先に設定する（ここを目的地にする）」** ボタンをタップします。
- 目的地に設定されたスポットには、カード上に大きく **「目的地」の朱印マーク** が押され、自動的にルートマップ画面へ移動します。
- スポットをめぐる順番は自由です。推奨順（1, 2, 3...）通りに歩いても、自分の現在地から近い場所を先に目的地にしても構いません。

### 2.3 ルートマップで現在地と目的地への方角・距離を確認する
- ルート詳細画面の **「現在の目的地への地図を見る」**、または各スポットの **「マップを表示」** をタップすると、ルート専用のマップ画面（`/routes/[id]/map`）が開きます。
- マップ上には以下の情報が表示されます：
  - **📍 赤いピン**: あなたの現在地
  - **🎯 朱色のパルス（脈動）ピン**: 現在設定している目的地スポット
  - **① ② ③ 番号ピン**: ルート内の各スポット
  - **朱色の破線と方向矢印**: 現在地から目的地へ向かう方角と直線ガイドライン
  - **画面下部のナビカード**: 現在の目的地名と、現在地からの残り距離（`あと 〇〇 m` / `あと 〇〇 km`）がリアルタイムに表示されます。
- マップ上のピンをタップすると、そのスポットの写真・距離が表示され、現在の目的地であればその場から **「しるしを刻む」** ボタンを押して押印画面へ進むことができます。

### 2.4 進行中のルートを切り替える・外す・再参加する
- **進行中から外す**: マイページ（`/mypage`）または進行中のルート一覧（`/mypage/active`）にある **「進行中から外す」** ボタンを押すと、いつでも進行中状態を解除できます（獲得済みのSHUINはそのまま保持されます）。
- **再参加する**: 過去に参加したことがあるルート、または一度完走したルートでも、ルート詳細画面の **「このルートに再参加する」** ボタンを押すことで、再び24時間「進行中」に設定して街をめぐることができます。

## 第3章：現地で押印し、物語を紡ぐ（押印・物語体験ドメイン）

目的地に到着したら、その場所の物語に触れ、訪れた証であるSHUINを刻みましょう。

### 3.1 スポットへの接近と「物語の幕（300m / 100m / 50m）」
- スポット詳細・押印画面（`/routes/[id]/spot/[spotId]`）を開いた状態で目的地へ歩いて近づくと、残り距離に応じて画面上部に **「物語の幕（Actバナー）」** が3段階で現れます：
  - **半径 300m 以内（幕・壱）**: スポット周辺に足を踏み入れた際の導入エピソード
  - **半径 100m 以内（幕・弐）**: スポットのすぐそばまで近づいた際の手がかりや風景の描写
  - **半径 50m 以内（幕・終）**: 到着を知らせる合図

### 3.2 現地での押印方法（GPS判定とQRコード読み取り）
1. スポット詳細・押印画面の下部にある「押印する」セクションで、現在地からスポットまでの距離がリアルタイムに計測されます。
2. 原則として **スポットから半径50m以内**（スポットにより指定範囲が異なる場合があります）に入ると、**「圏内です。押印できます。」** と緑色で表示されます。
3. **GPSで押印する場合**: 表示された朱色の **「押印する」** ボタンをタップします。
4. **QRコードで押印する場合**（現地QR対象スポットのみ）: **「📷 QRコードで押印する」** ボタンをタップし、カメラへのアクセスを許可して現地のQRコードを読み取ります。

> **💡 1日1回の押印ルールと再訪について**
> - 同じスポットへの押印は **1日1回まで（日本時間基準）** です。当日すでに押印済みの場合は「🎉 本日のしるしを刻みました」と表示されます。
> - 当日中は **「💮 セレモニーを再体験する」** ボタンから、何度でも押印アニメーションを楽しむことができます。
> - **別の日（翌日以降）に再び訪れた場合** は、「再訪」として新たに押印を刻むことができ、来訪回数（`来訪 N回目`）が積み重なっていきます。

### 3.3 押印セレモニーと「スポットの記憶（物語片）」
押印を実行すると、画面が暗転し、SHUINならではの **押印セレモニー（全6段階）** が始まります。
1. **和紙の展開と印の構え**: 画面中央に和紙が広がり、印が現れます。
2. **押印の瞬間**: 太鼓の響きと心地よい振動（対応端末のみ）とともに、インクの飛沫が舞い、ルートのテーマに応じた朱印が刻まれます。
3. **物語の断片と来訪者番号**: その場所に眠る短い物語の断片（再訪時は「おかえりなさい。再びこの地へ」のメッセージ）と、あなたがその場所を訪れた **「#〇〇番目の来訪者」** という固有の番号が刻まれます。
4. **ポストスキャンカード（「〇〇の記憶」）**: `➔` ボタンをタップすると、そのスポットの **物語全文** が記された「記憶のカード」が開きます。
   - まだ巡っていないスポットが残っている場合は、カード下部の **「次のスポットへ ➔ [次のスポット名]」** ボタンをタップすると、自動的に次の未押印スポットが目的地に設定され、マップ画面へ移動します。
   - ルート詳細画面の「💮 獲得したしるし帳」に並んだ印をタップすることでも、いつでも獲得済みスポットの「記憶の物語」を読み返すことができます。

### 3.4 今日の感想メモと思い出の写真を残す
- 押印直後の「ポストスキャンカード」内、または押印完了後のスポット詳細画面下部にあるフォームから、**一言感想メモ（最大100文字）** と **思い出の写真（1枚・📷ボタンから選択）** を保存できます。
- 保存した写真とメモは、マイページの「SHUIN帳」に刻まれ、いつでも当時の風景とともに振り返ることができます（「連れ立ち」で巡っている場合は同行メンバーにも共有されます）。

### 3.5 スポットの来訪履歴タイムライン「あなたとこの場所の記憶」を振り返る
- 過去に1回以上押印したことのあるスポット詳細画面（`/routes/[id]/spot/[spotId]`）を開くと、**「💮 あなたとこの場所の記憶（通算 N回来訪）」** セクションが表示されます。
- あなたがこれまでにその場所を訪れたすべての日付・来訪者番号（`#〇〇番目の来訪者`）・当時残した写真や一言メモ・連れ立ち記録がタイムライン形式で並び、同じ場所を季節や年月を超えて再訪した歩みを深く味わうことができます。

### 3.6 ルート完走・「自答の儀」と踏破印の授与
ルート内の **すべてのスポットで押印を完了** すると、ポストスキャンカードの下部に **「💮 ルート完走 — 踏破印を刻む」** ボタンが現れます。
1. **自答の儀（対象ルートのみ）**:
   - 「自由が丘で、"自由"の正体を探す」などの物語ルートでは、各スポットで集めた手がかりをもとに、あなた自身の解釈・答えを4つの選択肢から1つ選ぶ **「自答の儀」** が行われます。
   - 正解・不正解はなく、**あなたが選んだ答えによって授かる「副印（サブ）」が変わります**。
2. **完走セレモニー**:
   - これまでに巡った全スポットのしるしが走馬灯のように浮かび上がり、ひとつに収束して **「ルートの踏破印（メイン印＋自答の儀の副印）」** が完成します。
   - 完走カードには、授かった踏破印の名称、全スポットの制覇リスト、完走日、そして物語の結びの言葉が刻まれます。

### 3.7 完走称号カードを画像で保存・SNSシェアする
- 完走カード画面の **「称号カードを画像でシェア」** ボタンをタップすると、和紙と金枠をあしらった縦型の特製「朱印・踏破証画像（PNG）」が自動生成されます。
- スマートフォンの共有メニューからそのままSNSへ画像付きで投稿できるほか、端末に画像としてダウンロード保存することも可能です。

## 第4章：友人と「連れ立ち」で巡る（連れ立ち・グループ同行ドメイン）

「連れ立ち」は、友人や家族、パートナーと同じルートを一緒に歩きながら、お互いの到着や思い出の写真・感想をリアルタイムに共有できる機能です。

### 4.1 連れ立ちグループを作成し、6桁の招待コードを発行する
以下の2つの場所から、いつでも連れ立ちを開始できます：
1. **ルート詳細画面（参加中）**: **「👥 友達と連れ立ちを開始する」** ボタンをタップします。
2. **ルートマップ画面**: 画面右上の **「👥 友達を誘う」** ボタンをタップします。
- タップすると **6桁の招待コード（数字）** が発行されます。「コピー」ボタンを押して、一緒に巡る友人へLINEやメッセージ等でコードを伝えるか、その場で画面を見せてください。

### 4.2 招待コードを入力して友人のグループに合流する
招待コードを受け取った同行者は、以下の手順で合流します：
1. SHUINにログインし、**マイページ（`/mypage`）** を開きます。
2. 上部にある「友達と『連れ立ち』で巡る」カードの **「招待コードを入力」** ボタンをタップします。
3. 教えてもらった **6桁の数字** を入力して **「参加する」** をタップします。
4. 自動的に対象のルートが「進行中」に設定され、友人がいるルートマップ画面へ合流します。

### 4.3 リアルタイムの到着通知とマップ上の同行者表示
連れ立ちセッション中は、マップ画面（`/routes/[id]/map?groupId=...`）で以下の連携が行われます：
- **お祝いトースト通知**: 同行メンバーがいずれかのスポットで押印すると、あなたの画面上部に **「🌸 〇〇さんが『スポット名』に到着し、しるしを刻みました！」** とリアルタイムで通知が表示されます。
- **同行者の滞在ピン**: マップ上に、同行メンバーのアイコン（最後に押印したスポット位置）が表示されます。
- **スポットごとの獲得メンバー表示**: マップ上のスポットピンをタップすると、「しるしを獲得した同行者」のアイコン一覧を確認できます。

### 4.4 思い出の写真・一言メモのグループ共有と「連れ立ち思い出アルバム」
- 連れ立ち中にスポットで押印し、「感想メモ」や「思い出の写真」を送信すると、同じグループの同行メンバー全員にリアルタイムで共有されます。
- **ルートマップ上の「連れ立ち思い出アルバム」**: 連れ立ち中のマップ画面上部バーにある **「📷 アルバム（N）」** ボタンをタップすると、そのルートで自分や同行メンバーが撮影した写真・一言メモが一覧で並ぶ **「連れ立ち思い出アルバム」モーダル** をその場で開いて楽しめます。
- **後日SHUIN帳からの写真・あとがき追加**: 街歩きの最中に写真を撮りそびれたりメモを書き忘れたりしても、帰宅後に「SHUIN帳」から写真やコメントを追加すると、同行メンバーのアルバムにも反映されます。
- 後日、各自の「SHUIN帳」からそのスポットの押印記録を開くと、**「👥 〇〇さんと一緒に巡りました」** という同行記録とともに、**友人が撮影した写真やメモ**（「〇〇さんが共有」と表示）も一緒に振り返ることができます。

### 4.5 連れ立ちの終了（解散・退出）
- ルート詳細画面（`/routes/[id]`）の「連れ立ちセッション進行中」カードにある **「連れ立ちをやめる」** ボタンをタップすると、連れ立ちを終了してソロプレイに戻ることができます。
  - **グループを作成した人（立ち上げ人）** が押した場合：グループ全体が終了（解散）します。
  - **合流したメンバー** が押した場合：そのメンバーのみがグループから退出し、ソロプレイに戻ります。
- ※連れ立ちを終了しても、それまでに一緒に巡った記録や共有された写真はSHUIN帳から消えません。

## 第5章：歩みを振り返り、称号を授かる（SHUIN帳・称号ドメイン）

街を歩いて刻んだしるしや物語は、すべてあなたのライフログとして蓄積されていきます。

### 5.1 SHUIN帳の2つの表示モード（「朱印帳グリッド」と「旅のアルバム」）
- 右上のメニューアイコンから **「SHUIN帳」**（`/mypage/diary`）、またはマイページの「最近の来訪日記 ＞ すべて見る」をタップします。
- 画面右上の切り替えボタンで、2つのビューを自在に切り替えられます：
  1. **朱印帳グリッド**: 伝統的な御朱印帳のように、刻んだ朱印影が一覧で並ぶビューです。
  2. **旅のアルバム（日記帳ビュー）**: 訪れた日付・街・ルート名・当時の写真・思い出のあとがき（感想メモ）・スポットの物語の断片を、1ページずつ日記帳をめくるように味わえるライフログビューです。

### 5.2 ライフログ絞り込みチップ（連れ立ち・写真・再訪・訪れた街・年月）
- SHUIN帳では、以下のフィルターを組み合わせて大切な記憶をすぐに探し出せます：
  - **ライフログ絞り込みチップ**:
    - `すべて`: 全記録を表示
    - `👥 連れ立ちの記憶`: 友人や家族と一緒に巡った押印記録
    - `📷 写真・言葉あり`: 思い出の写真や一言メモ（あとがき）を残した記録
    - `🔄 再訪した場所`: 2回以上訪れた「なじみの場所」の記録
  - **訪れた街（市区郡）フィルター**: `目黒区`、`さいたま市岩槻区` など、実際に足跡を残した街ごとに絞り込めます。
  - **年月タブ**: `すべて` / `2026年10月` など、歩いた時期ごとに絞り込めます。

### 5.3 「ルートの踏破印（メイン印・自答の儀の副印）」を振り返る
- SHUIN帳の上段には、最後までめぐり終えたルートの **「💮 ルートの踏破印」** カードが並びます。
- メインの踏破印名と完走日に加え、「自答の儀」であなたが選んだ答えに対応する **「サブ（自答の儀）」の副印名と解説** が刻まれています。カードをタップするとそのルートの詳細画面へ移動できます。

### 5.4 「スポットの来訪印」の詳細と「思い出のあとがき・写真」の追記・編集
- SHUIN帳の各来訪印をタップ（または「旅のアルバム」ビューの編集ボタンをタップ）すると **詳細モーダル** が開き、以下の記録を振り返り・編集できます：
  - **第〇〇番のしるし**（来訪者番号）、**来訪回数バッジ（`🔄 N回目の来訪`）**、大きな朱印影
  - **訪れた日付・時刻**、**街（エリア）名**、**巡ったルート名**
  - **同行したメンバーの名前と共有された写真・メモ**（連れ立ち時）
  - **思い出のあとがき（感想メモ）の追記・編集**: 現地でメモを残せなかった場合や、帰宅後に改めて言葉を添えたい場合でも、**「✏️ 思い出のあとがきを綴る（編集する）」** からいつでも言葉を刻み直すことができます。
  - **思い出写真の追加・差し替え**: モーダル内の **「📷 写真を刻む（変更する）」** から、後からスマートフォン内の写真を登録することも可能です。

### 5.5 参加したルート一覧の確認と再参加
- SHUIN帳上部の右側カード **「巡ったルートの数（参加したルート一覧 ▸）」** をタップすると、これまでに参加・押印したすべてのルートが最新順でモーダル表示されます。
- 各ルートのステータス（`進行中` / `完走` / `参加履歴`）と **「獲得したしるし（印）の数（例: 3 / 5 個）」** の進捗バーを確認でき、**「ルートの詳細へ（再参加）」** ボタンからいつでも続きをめぐることができます。

### 5.6 称号システム（6大カテゴリ・15段階の境地）と「称号授与の儀」
SHUINでは、ルートごとの踏破印とは別に、サイト全体でのあなたの歩みの積み重ねに応じて **「称号」** が授与されます。
1. **新着バッジ通知と「称号授与の儀」**:
   - 新たな称号の条件を達成すると、画面右上のプロフィールアイコンおよびマイページの「最近獲得した称号」に **赤い新着バッジ（件数）** が表示されます。
   - **「称号を受け取る」**（`/badges`）を開くと、厳かな **「称号授与の儀」** が始まり、「？」と記された金の封印球が現れます。
   - **封印をタップして開封** すると、レア度（★1 銅・常しるし 〜 ★5 虹・伝説しるし）に応じた光と火花のエフェクトとともに、授かった称号が明かされます。
2. **6大カテゴリと15段階のレベルアップ称号（「目録 ➔ 免許 ➔ 皆伝」）**:
   - 称号一覧画面（`/badges`）では、レア度（★1〜★5）や「未取得も表示 / 取得済のみ」で絞り込みながら、以下の6つのカテゴリで現在の境地を確認できます：
     - **地域（エリア）**: 市区郡単位（例：`目黒区探索目録 壱` 〜 `皆伝 伍`）で訪れたスポット数に応じた15段階
     - **路線沿線**: 鉄道路線沿線（例：`東急東横線沿線目録 壱` 〜 `皆伝 伍`）で訪れたスポット数に応じた15段階
     - **都道府県**: 都道府県単位（例：`東京都逍遥目録 壱` 〜 `皆伝 伍`）で訪れたスポット数に応じた15段階
     - **印目（カテゴリ・属性）**: ルートのテーマ別（例：`地域探究目録 壱` 〜 `皆伝 伍`）に訪れたスポット数に応じた15段階
     - **一般（全体実績・継続）**: 初めての押印（`初めての一歩`）や、累計押印数（1箇所〜100箇所）に応じた15段階（`しるし刻みし目録 壱` 〜 `皆伝 伍`）、物語収集実績など
     - **特別・その他（季節・イベント）**: 桜の頃（3/20〜4/10）、盛夏（7/20〜8/20）、紅葉（10/15〜11/15）、冬至（12/19〜12/25）、年越し（1/1〜1/3）などの季節限定称号や、ベータ探索者称号など
   - ※15段階のレベル称号は、同じ地域や路線の中で **現在到達している最高位の境地（未取得の場合は最初の目標である「目録 壱」）** が代表として美しく表示されます。

## 第6章：アカウント・マイページ・設定（アカウント・設定・お知らせドメイン）

### 6.1 Googleアカウントでのログイン・新規登録
- SHUINは **Googleアカウント連携（OAuth）** を採用しています。パスワードを新たに設定・管理する必要はなく、ログイン画面（`/login`）の **「Googleでログイン / 登録」** ボタンをワンタップするだけで、新規登録およびログインが完了します。

### 6.2 マイページ（ダッシュボード）の見方と「街歩きの軌跡」「記憶の一頁」
ログイン後に画面右上のプロフィールアイコンからアクセスできる **マイページ（`/mypage`）** では、あなたの人生の歩みと現在の状況を一覧で確認できます：
- **プロフィール・設定・ログアウト**
- **友達と「連れ立ち」で巡る（招待コード入力ボタン）**
- **🗺️ あなたの街歩きの軌跡（ライフログ集計）**:
  - **訪れた街（市区郡）**: これまでに足跡を残した街の数と、訪れた市区郡のタグ一覧
  - **刻んだしるし（累計押印）**: 累計の押印数と、同じ場所を再び訪れた「なじみの再訪」回数
  - **巡り終えた物語（完走）**: 最後まで歩ききって踏破印を授かったルート数
  - **紡いだ思い出**: 友人と歩いた「連れ立ち」回数と、写真や言葉を刻んだ記録件数
- **🌸 記憶の一頁（あの日のしるし）**:
  - これまでに訪れたスポットの中から、写真やあとがき・連れ立ちの思い出が残る印象的な一場面を和紙カードに浮かび上がらせます。**「🔄 別の記憶をめくる」** ボタンで過去のさまざまな記憶を振り返ることができます。
- **街の便り（最新のお知らせ1件と一覧へのリンク）**
- **進行中のルート（現在の進捗バー、残り有効時間、連れ立ち状況、再開・解除ボタン）**
- **最近獲得した称号（最新3件と新着通知バッジ）**
- **最近の来訪日記（直近3件の押印履歴とSHUIN帳へのリンク）**
- **保存したルート（栞を挟んだブックマーク一覧 `/mypage/bookmarks` へのリンク）**

### 6.3 「街の便り」で新ルートやイベント情報を確認する
- ヘッダーメニューまたはマイページから **「街の便り」（`/notifications`）** を開くと、新しく公開されたルート、機能のアップデート情報、季節限定の称号イベントなどのお知らせを確認できます。
- 各お知らせカードをタップすると詳細本文が開きます。

### 6.4 各種設定・ログアウト・退会手続きについて
- **設定画面（`/settings`）** では、登録中のプロフィール（表示名・メールアドレス）の確認、プッシュ通知設定の切り替え（※配信機能は現在準備中）、利用規約（`/terms`）・プライバシーポリシー（`/privacy`）の確認、およびログアウトが行えます。
- **退会（アカウント削除）をご希望の場合**: 設定画面下部の「退会する」ボタンをタップし、案内に従ってお問い合わせ窓口までご連絡ください。
